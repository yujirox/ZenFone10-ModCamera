# ZenFone10-ModCamera
Magisk module for silencing the ZenFone 10’s camera.  
  
This is the ZenFone 10’s standard camera (com.asus.camera) package with sound effects muted.  
The sound effects in the following audio files, with the exception of the self-timer, have been muted:  
1p.ogg: Self-timer  
bE.ogg: Shutter  
bG.ogg: End of video  
cN.ogg: Fast self-timer  
iT.ogg: Video start  
q0.ogg: Self-timer (low volume)  
R2.ogg: Focus  
ZK.ogg: Fast self-timer (low volume)  
  
Compatibility has been confirmed on OS version 35.0604.0404.165.
